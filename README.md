# 🍳 CookVen - La Cocina del Futuro

Bienvenido al repositorio oficial de **CookVen**, una plataforma diseñada para optimizar recetas con una interfaz fluida y moderna. Este proyecto es una iniciativa de **PerfectVerso** enfocada en el arte culinario contemporáneo.

## 🚀 Tecnologías Utilizadas
Este sitio web es una aplicación estática de alto rendimiento construida con:
* **HTML5:** Estructura semántica.
* **CSS3:** Diseño minimalista y responsivo con estética "Dark Mode".
* **JavaScript (Vanilla):** Lógica de interfaz y respuesta instantánea.
* **Formspree:** Gestión de comunicaciones y soporte técnico.

## 📱 La Aplicación
CookVen ofrece una solución integral para los amantes de la cocina, permitiendo el acceso a herramientas de gestión culinaria directamente desde el navegador o mediante su aplicación móvil.

## 🛠️ Seguridad y Transparencia
Este proyecto es de carácter educativo y personal. No recopila datos sensibles sin consentimiento y utiliza servicios de terceros confiables para la gestión de mensajes y alojamiento.
